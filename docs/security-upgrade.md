# Dashboard 安全更新升级说明

本次更新修复 NAT/DDNS 跨用户授权、账户和旧 OAuth 登录、服务器转移期间的控制权限，以及匿名请求和异常 Agent 的资源消耗问题。升级 Dashboard 前请备份数据库和配置文件。

## 需要调整的配置与客户端

- **成员 NAT**：管理员必须设置 `dashboard_host`，并在管理后台「设置」的「成员 NAT 域名名单」（或配置文件 `nat_member_domains`）中明确列出可供成员使用的完整域名。后台每行一个域名，保存后对新连接生效，无需重启。默认空列表禁止成员 NAT。域名不支持通配符或后缀匹配，比较时忽略端口、大小写及结尾的 DNS 点。管理员创建的 NAT 不受成员名单限制，但所有用户均不能占用面板保留域名。名单不等于按用户分配域名；需要独占管理时由管理员创建 NAT。旧版后台仍可使用，但只能通过配置文件设置名单并重启；旧客户端省略该字段不会清空已有名单，显式空数组会禁用成员 NAT。
- **已有 NAT**：每次路由匹配和连接建立都会检查创建者身份、服务器所有权与域名配置，包括禁用记录。升级前遗留的越权记录不会继续占用面板路由。NAT 仅支持 HTTP/1.1；HTTP/2 明确返回 505。正文上限 64 MiB，每个进程最多同时处理 128 个 NAT 请求，连接最长 5 分钟。
- **DDNS**：绑定不存在的配置 ID 会被拒绝。运行时只使用服务器所属用户自己的 DDNS 配置，管理员配置不再隐式共享给其他用户。原先依赖共享的部署需要为对应所有者配置独立 DDNS 凭据，并清理不再有效的绑定。
- **计划任务 PAT**：创建或修改命令任务必须同时拥有 `nezha:cron:write` 和 `nezha:cron:exec`，仍受服务器白名单限制。请更新依赖仅写权限的自动化客户端。
- **登录与修改资料**：登录接口只接受 `application/json`，拒绝空用户名、空密码及跨站来源。修改资料时空的新用户名或新密码保留原值；非空新密码必须为 8–72 字节，仍需验证原密码。
- **旧第三方 OAuth 登录**：绑定必须由已登录会话发起并由同一用户、同一会话完成；state 有效期 5 分钟且只能消费一次。无有效用户 ID、非 2xx 或大于 1 MiB 的 userinfo 响应会被拒绝。历史空 ID 绑定无法再用于登录；受影响用户需使用其他登录方式重新绑定。这与 MCP OAuth 授权流程不同。
- **服务与告警**：服务检查间隔最长 30 天；超限历史记录在启动时跳过并记录日志。告警历史窗口上限为 86400；不安全的旧记录不参与计算，需调整后恢复。新建或修改周期告警时 `cycle_start` 不得早于 2000 年。日历周期计算按周期跨度直接定位，避免从很早的日期逐次遍历；月末日期保留顺序归一化规则，日/周跳跃保持起点的本地时刻（跨夏令时不再累积不存在时刻的偏移）。

配置示例（请替换成实际域名，并把其他面板入口加入 `reserved_hosts`）：

```yaml
dashboard_host: panel.example.com
reserved_hosts: admin.example.com
nat_member_domains:
  - tunnel.example.com
```

## 转移和资源限制

转移或凭据回滚尚未确认完成时，非管理员不能读取/修改 Agent 配置、建立终端/文件流、使用 NAT 或执行 MCP 控制操作。授权检查与所有权变更协调，排队任务发送前重新检查权限；已有流按转移规则撤销。转移前签发的 MCP 文件链接永久失效，即使后来回滚也不能恢复使用。

此措施限制转移窗口内的新操作，不会抹除服务器文件系统中的历史凭据、终止已经开始的任意操作系统命令，也不能替代主机交接清理。将主机交给其他用户前仍应移除不应共享的配置和备份。

Agent 任务发送期限为 1 秒，每条连接排队最多 16 项；阻塞连接需要重连，未交付任务不保证重试。其他 Agent 的探测、保活和定时任务不再被同一个阻塞发送拖住。异常非有限浮点值会归零；上报 IP 必须符合对应地址族格式，格式校验不代表地址所有权证明。

关闭 MCP 后，文件入口返回 404 且不写匿名失败审计。启用时，匿名失败审计按来源限额并共享每分钟 60 条上限，审计队列有界，维护任务删除超过 90 天的记录。每个进程最多同时保留 32 个下载 spool，单文件仍为 100 MiB，并设置传输写入期限；反向代理仍需配置适当的连接限制。

访问日志不再记录查询参数和文件传输路径中的凭据。文件配置中的 JWT 签名密钥在保存设置后保留；通过 `NZ_JWTSECRETKEY` 注入的密钥不写入配置文件，也不包含在公共 JSON 响应中。
